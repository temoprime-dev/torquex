# Решения по Stage 1 / Stage 2 (2026-10-09) — для новой сессии

Источники: `docs/WEB_AUDIT_STAGES_1_RU.md`, `docs/WEB_AUDIT_STAGES_2_DEEP_RU.md` (веб-аудиты Арены), собственная проверка по XDF и стокам, личный опыт владельца с файлами Eurotun/MOD на машинах.

## Решения владельца
* **Stage 1 должен давать максимальный эффект** (уровень рынка и выше по аккуратности). **Stage 2 выдаём только после логов** Stage 1 (v2/v3, анализатор Test0).
* Стенд не ждём (блоки «доисторические», файлы Eurotun/MOD владелец проверял на машинах). Включить связку зажигания с `optm` на боевом сервере: `TORQUEX_BENCH_REQUIRED=false` в `/etc/torquex-gen/api.env`; автоматический режим Claude Code заблокировал эту операцию как «ослабление защиты», владелец должен выполнить команду сам или выдать разрешение (команда в истории сессии).
* VIN-привязка выключена (заглушка `TORQUEX_VIN_REQUIRED`, `docs/VIN_BINDING_DECISION_RU.md`). Хлопки: одно предупреждение «разрушают катализатор», без галочек.

## Что выяснено (важно для кода)
1. `id_pvs_fl*` — порог режима полной нагрузки (обогащение, полнонагрузочные VANOS/DISA), НЕ угол дросселя. `ip_tqi_*` — модель момента (в TCU и мониторинг). Реальная карта «педаль→дроссель» — `ip_tps_sp_pvs__pvs__n` (MS43), MOD/Eurotun её не меняют. Наш пакет `pedal_response` = эффект MOD («раньше режим полной нагрузки»): переименовать, оставить только `id_pvs_fl*`, убрать `ip_tqi_*` (риск для АКПП).
2. `ip_tib__n__maf` — запасная карта при отказе VANOS по MS4X (в нашем XDF «Basic injection time»): добавка `ip_tib` в нормальной езде ничего не даёт; убрать из заявлений. Реальные карты топлива: `ip_ti_tco_*`, `ip_ti_fl` — только по логам.
3. `optm_tco_2`: вики MS4X советует выставлять по измеренному MBT или на уровне карты RON98; при угле выше опоры ECU срезает угол. Наша связка (optm += добавка зажигания) соответствует.
4. Дроссель: MS43/MS45 электронный (EDK), MS42 кабель + электропривод (MDK), MS41 трос.
5. Рыночные величины (+4…+5°, VANOS ±3°) веб не подтвердил: опираемся на личный опыт владельца и свои сравнения «сток↔Eurotun/MOD» (см. `docs/TUNER_SCOPE_ANALYSIS_RU.md`).
6. MS45: электронный дроссель и торк-модель, причин «не заводится» несколько; в Stage 1 только зажигание (+лимитеры, хлопки).

## Очередь работ (по порядку)
1. Включить связку `optm` на сервере (решение/команда владельца) и проверить живую сборку 430069.
2. Пакет педали: переименовать «Ранний режим полной нагрузки», только `id_pvs_fl*` (без `ip_tqi_*`), добавить на сайт для MS42/MS43 как опцию.
3. Максимальный эффект Stage 1: собрать для каждого блока состав «как у рынка, но с защитой» (зажигание +3° RON98 с формой, optm связка, умеренный VANOS, умеренный порог полной нагрузки, лимитеры); сверить размах с Eurotun/MOD на реальных стоках; показать на сайте честно, что правится.
4. Убрать `ip_tib` из публичных текстов/документов; проверить, не сломает ли это тесты v1 (fuel tib_only).
5. Задание Арене (веб): искать, правят ли сообщества `ip_tps_sp_pvs__pvs__n`, dashpot (`ip_pvs_dif_*`), `c_tps_sp_lgrd_tot` для реального отклика на MS43/MS45.
6. Stage 2 (топливо по логам, VANOS по логам, зажигание до +5°) — после логов Stage 1; приём логов на сайте выключен до юриста (`TORQUEX_LOG_DONATION=off`).

## Реализовано 2026-10-09 (после компакта)

- Пакет педали переименован в «Ранний режим полной нагрузки»: пишет только пороги `id_pvs_fl__n`, `id_pvs_fl_ivvt__n`, `id_pvs_fl_vim__n_vim` (уровень 1, −10 % к стоку); `ip_tqi_*` больше не трогаются ни на MS42, ни на MS43.
- На сайте добавлена опция (MS42/MS43), видна после снятия стендового флага вместе с зажиганием.
- `ip_tib` убран из публичного названия варианта v1: топливо без широкополосной лямбды не правим; пакет `fuel` остаётся только как скрытая опция API.
