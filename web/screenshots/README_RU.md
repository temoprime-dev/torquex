# Скриншоты сайта

Снимки в этом раунде не получены: в рабочей среде нет браузера и средств
headless-съёмки. Ниже — инструкция для ручной проверки. Скриншоты сохраняйте
в этот каталог; он исключён из проверки размера фронтенд-бандла.

## Что снять

Минимум — старт мастера и шаги 1–4 на ширинах **375 px** и **1440 px**.
Дополнительно проверьте шапку и отсутствие горизонтальной прокрутки при
**414 px** и **768 px**. Для шагов 2–4 используйте только `?demo=1`: демо-ответы
вымышленные, файл не отправляется на сервер. Не загружайте клиентские стоки в
публичные снимки.

| Экран | Состояние |
|---|---|
| Старт / шаг 1 | Обычный `index.html`: зона загрузки, privacy-строка и компактный статус доверия |
| Шаг 2 | В демо выбрать локальный файл-заглушку от 4 КиБ; после определения видны ЭБУ, версия и варианты |
| Шаг 3 | Нажать выбор v1; октан, обороты и хлопки показаны первыми, «Ещё опции» свёрнуты |
| Шаг 4 | Выбрать октан и нажать «Собрать»; появится demo-результат с кнопкой «Скачать» |
| Правовой блок | В шаге 3 включить хлопки: видны подтверждение снятого катализатора и правовая справка |

## Ручная съёмка

1. В отдельной временной папке создайте безопасный файл-заглушку больше 4 КиБ
   (он нужен только для перехода демо к успешному определению):

   ```bash
   python -c "from pathlib import Path; Path('demo-placeholder.bin').write_bytes(bytes(8192))"
   ```

2. Из корня репозитория запустите статический сервер:

   ```bash
   python -m http.server 8000 --directory web
   ```

3. Откройте `http://127.0.0.1:8000/index.html` для обычного стартового экрана.
   Для остальных шагов откройте `http://127.0.0.1:8000/index.html?demo=1`,
   выберите `demo-placeholder.bin` и дождитесь автоматического перехода к
   определённой версии и вариантам. В демо-режиме файл не отправляется на API.

4. В DevTools включите responsive/device toolbar и по очереди задайте ширины
   375, 414, 768 и 1440 px. Снимите шаги, переключая v1, опции и результат.
   Для шага 4 выберите значение октана, оставьте хлопки выключенными и нажмите
   «Собрать».

5. Используйте функцию браузера «Capture screenshot» / «Снимок экрана» и
   сохраните файлы с понятными именами, например:
   `01-start-375.png`, `02-variants-1440.png`, `03-options-375.png`,
   `04-result-1440.png`. После проверки удалите локальный файл-заглушку.

Для проверки только верстки API не нужен. DevTools-снимок — визуальная
проверка; статические тесты сами по себе не измеряют фактическое число экранов
и не доказывают отсутствие горизонтальной прокрутки в браузере.
