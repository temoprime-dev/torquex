Итого: **10 семейств, 239 калибровок, суммы 239/239**; поддержаны все десять —
у каждого семейства разрешены роли `vmax`, `rev_limit_mt/at/amt` и `pops_delay`
(у BO00S/LO00S дополнительно карты и слои диагностики). Прежняя проверка «взять
адрес XDF и подставить в чужое семейство» давала бессмыслицу (в колонке «почему»
раньше печатались эти значения) — именно поэтому адреса доказываются отпечатками
по стокам **своей** семьи.

## 3. Как доказаны адреса у семи семейств без XDF

Ни XDF, ни размеченных XML-таблиц требуемых ролей у этих семейств нет, поэтому
каждая роль доказывается **структурным отпечатком по всем стокам семьи**:

* отпечаток обязан **воспроизвести известный адрес** у семейств с
  первоисточником (BO00S/LO00S — XDF, BN00S — XML) — защита от подгонки;
* в калибровке каждой семьи отпечаток обязан сработать **ровно один раз** и на
  **всех** её стоках;
* адрес обязан совпасть с `definitions/stock_derived_maps.json`, иначе
  `policy --validate` падает.

Отпечатки четырёх ролей и таблица адресов по всем семи семьям —
`FAMILY_CALIBRATION_EVIDENCE_RU.md` §2–3; воспроизводимая реализация —
`MS45/tests/test_family_stock_proof.py`.

**Зажигание (карта RON98), 2026-10-08.** У `4560BL00S`, `4560BM00S`,
`4570LL30S`, `4570LM00S`, `4570LN00S` адрес карты RON98 и её осей доказан
отпечатками кластера карт зажигания и цепочки записей осей: на BO00S/LO00S/BN00S
отпечатки дают адреса XDF/XML, в каждой из пяти семей — один адрес во всей
калибровке и во всех стоках, `RON98 ≥ RON91` не менее чем в 95% ячеек на каждом
стоке (для BL00S дополнительно совпадает с XML-определениями ROM `4560BL00`).
Реализация — `MS45/tests/test_family_ignition_proof.py`, таблицы —
`FAMILY_CALIBRATION_EVIDENCE_RU.md` §4. У `4560BL30S` и `4570LL00S` по одному
стоку — зажигание `REQUIRES_DATA` («нужен второй образ»).

## 5. Как перепроверить самому

```bash
# суммы всех калибровок и дампа
python3 -m MS45.tools.checksums MS45/firmware MS45/firmware_spdaten/cal MS45/firmware_dumps

# определения: объекты, область калибровки, вырожденные формулы
python3 -m MS45.tools.xdf --family 4560BO00S
python3 -m MS45.tools.xdf --family 4570LO00S

# определения сообщества: ROM 4560BN00 и его роли (источник адресов BN)
python3 -m MS45.tools.xml_defs --rom 4560BN00 --grep "limiter|overrevving|trailing"

# тесты семейства BN (источник, данные, ядро, генератор)
python3 -m unittest MS45.tests.test_bn00s

# поддержка BM00S и отказ на синтезированном чужом семействе
python3 -m unittest MS45.tests.test_bm00s

# отпечатки четырёх ролей и сборка на всех стоках новых семейств
python3 -m unittest MS45.tests.test_family_stock_proof MS45.tests.test_pops_delay_group

# карта RON98 у пяти семейств без XDF: отпечатки, сборка Stage 1 и независимая проверка байтов
python3 -m unittest MS45.tests.test_family_ignition_proof
python3 -m MS45.tools.map_match --validate-baselines

# политика: сборка из данных и проверка
python3 -m MS45.tools.policy --build --show && python3 -m MS45.tools.policy --validate

# тесты (Linux и Windows; вывод CLI проверяется на cp1251)
python3 -m unittest MS45.tests
```
