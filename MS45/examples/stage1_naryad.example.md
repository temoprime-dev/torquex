## Что НЕ менялось

* области вне калибровки `0x40000..0x5CFFF`: загрузчик/системная часть, 
  программа `0x60000..0xFFFFF`, внутренняя флеш MPC и запись программатора;
* RSA-подпись калибровки (`0x174..0x1B3`) — не пересчитывается и не восстанавливается;
* штатные защиты: `c_n_lim_min` (порог «overrevving event», 7200 rpm), 
  детонация, температурные ограничения, `c_t_min_pu_msr`.

## Предупреждения

* **Мощность не обещается.** В наряде нет ни одной цифры прироста: без стенда 
  это было бы выдумыванием.
* **Подпись.** Любая правка калибровки делает RSA-подпись недействительной — 
  она не входит в наши суммы и не восстанавливается (нет ключа BMW). Файл 
  предназначен для прошивки тюнинг-флешером области `0x40000..0x5CFFF`; путь 
  штатного WinKFP/ISTA требует переподписи на стороне, которая её умеет.
* **Только эта калибровка.** Адреса и границы сняты со стока именно этого 
  семейства; в другой версии прошивки записанные значения означают другое.
* **Хлопки.** Разрешены только без катализатора и требуют контроля температуры 
  выпуска. Агрессивные пресеты не выпускаются.
* **Отсечка.** Выше 6900 rpm на M54B30 требуется демпфер крутильных 
  колебаний (ms4x.net); штатный порог 7200 rpm остался на месте.

## Откат на сток

* sha256 стока (исходный образ): `95b4e1fc7509595fb7222681e34f3dbf4f202600674387f2257215aa93093451`
* исходный сток сохраняется копией до записи: ровно тот файл, чей sha256 указан в поле source_sha256 (95b4e1fc7509595f…)
* возврат — записью этого файла тем же способом, что и тюн (полная запись область калибровки 0x40000..0x5CFFF); ЭБУ после отката принимается штатной диагностикой
* после возврата сверить sha256 поступившего файла с source_sha256 манифеста; несовпадение — файл повреждён или это другой сток, записывать нельзя
* проверка выпущенного файла перед записью и после отката: python3 -m MS45.tools.stages --verify-manifest <манифест>.json --image <файл>

```
python3 -m MS45.tools.stages --verify-manifest <манифест>.json --image <файл>
```

## Порядок прошивки

1. Сохранить исходное чтение ЭБУ (полный образ 1 МиБ или калибровку 116 КиБ).
2. Прошить файл области калибровки `0x40000..0x5CFFF` (тюнинг-флешер, 
   «tune flash»); программа и нижняя область не записываются.
3. Убедиться, что ЭБУ не сообщает ошибок по контрольным суммам 
   (обе суммы в файле уже пересчитаны).
4. Первый запуск — на месте, с контролем: холостой ход, отсечка, 
   ограничитель скорости, ошибки в памяти неисправностей.

## Проверка файла

```
python3 -m MS45.tools.checksums <файл> --explain
python3 -m MS45.tools.stages --verify-manifest <манифест>.json --image <файл>
```

Вторая команда сверяет файл с манифестом: суммы, семейство, каждая ячейка 
плана и отсутствие изменений вне плана и вне калибровки.
