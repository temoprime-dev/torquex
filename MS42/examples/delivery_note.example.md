## Что нужно проверить после прошивки

- log vehicle speed and check the cylinder-shutoff stage engages where expected
- the hard stage cuts the fuel pump at c_vs_max_1 + c_vs_max_add; verify the value is above the soft stage
- log the limiter event: soft limiting must cut cylinders before the hard limiter cuts all of them
- hard cut engages here; verify no lean spike or misfire DTC
- hysteresis before injection is re-enabled; too small makes the limiter chatter
- hysteresis before all injectors return; must be >= hysteresis_rpm

Статус проверки на момент выпуска наряда: **НЕ ВЫПОЛНЕНА** — наряд построен по расчёту, а не по результатам заездов.

## Границы

- Зажигание, топливные карты и хлопки в наряд не входят: для них нужны логи, широкополосная лямбда и стенд (см. `docs/EVIDENCE_REQUIREMENTS_RU.md`).
- Ограничитель оборотов поднимается только выше стока и только с явным подтверждением риска: клапанный механизм, масляный насос и штатная защита рассчитаны на заводской предел.
- Режим «(MAF Hack 2048kg/h)» не применяется: он требует патча программной части, а не правки калибровки.
- Файл подготовлен для записи внешним флешером; этот наряд прошивку не выполняет и не заменяет проверку на машине.
- Значения с источником `customer_intent` — это пожелание клиента, а не измеренный оптимум.
- Проверены только те записи CRC, которые есть в образе: для полного чтения 512 КиБ это `boot`, `cal` и `prog`.
